# Radar Black Friday

Painel ao vivo da Black Friday de 27/11/2026. Mostra só as ofertas que estão dentro do limite de preço (total no cartão de crédito), com cupons do Mercado Livre, Amazon e Shopee.

Os dados ficam em `dados.json` e são atualizados automaticamente a cada 5 minutos. A página recarrega os dados sozinha a cada minuto.

Filtro por produto no link: `#tv`, `#ps5`, `#kindle`, `#tangle` (dá para combinar, ex.: `#tv-ps5`).
